# AlohaTours - Система работы турагентства

## 🌴 Версия 2: Windows Vista & Vaporwave Edition

Вторая версия проекта приносит радикальное обновление пользовательского интерфейса, вдохновленное эстетикой **Frutiger Aero, Windows Vista и светлым Vaporwave (Гавайские мотивы)**. 

### Что нового (Чейнджлог Версии 2)
1. **Глубокий редизайн (Aero Glass)**
   - Добавлены эффекты полупрозрачного размытого стекла (backdrop-filter).
   - Внедрены неоновые градиенты и ретро-шрифты (`Segoe UI`).
   - Использован сгенерированный светлый фоновый пейзаж (яркое небо, пляж, пальмы).
2. **Разделение логики Frontend**
   - Код был декомпозирован: HTML-разметка, CSS-стили и JavaScript-логика разнесены по отдельным файлам (`index.html`, `style.css`, `script.js`).
3. **Фильтрация и поиск**
   - На клиентскую часть добавлен "живой" поиск по стране и названию тура. Клиенту больше не нужно искать туры вручную.
4. **Реальные данные (Seeding)**
   - Написан скрипт `seed.py`, который автоматически наполняет базу данных реальными турами (Неоновые ночи Майами, Гавайи, Токио, Кипр) для быстрой демонстрации работы приложения.

## 💾 Версия 1: MVP (Минимально жизнеспособный продукт)

### Что это такое?
AlohaTours — это веб-система для управления туристическим агентством. Проект поддерживает ролевую модель: клиенты могут выбирать туры и оформлять заявки, а менеджеры — управлять каталогом.

### Как это работает?
1. **Клиентская часть:** SPA на HTML/JS/CSS.
2. **Бронирование:** Авторизованные клиенты могут забронировать тур. Цена фиксируется.
3. **Серверная часть:** FastAPI + SQLite/PostgreSQL (SQLAlchemy).

### Технологический стек
- **Backend:** Python 3.10+, FastAPI, Uvicorn, SQLAlchemy
- **Frontend:** Vanilla JavaScript, HTML5, CSS3
- **Безопасность:** JWT, Passlib (Bcrypt)

### Предметная область
1. **User (Пользователь):** `client` или `manager`.
2. **Tour (Тур):** Информация о путевке.
3. **Order (Заявка):** Связь пользователя и тура.

## Как запустить проект локально?

1. Склонируйте репозиторий.
2. Создайте виртуальное окружение: `python -m venv venv`
3. Активируйте его: `venv\Scripts\activate` (Windows)
4. Установите зависимости: `pip install fastapi uvicorn sqlalchemy passlib[bcrypt] python-jose python-multipart pydantic-settings`
5. **Наполните БД реальными турами:** `python seed.py`
6. Запустите сервер: `uvicorn backend.main:app --reload`
7. Откройте браузер по адресу: `http://127.0.0.1:8000/`
