# NovaTours (ранее AlohaTours) - Система управления туристическим агентством

## Описание проекта
NovaTours — это комплексная веб-система для управления туристическим агентством. Проект реализует ролевую модель (клиенты и менеджеры) и предоставляет единую информационную среду для автоматизации процессов бронирования путевок и аренды недвижимости.

Система позволяет клиентам самостоятельно подбирать туры через удобный интерфейс-агрегатор, оформлять заявки с фиксацией цены, а менеджерам — централизованно управлять каталогом и статусами бронирований.

## Среда разработки и Технологический стек

### Backend (Серверная часть)
*   **Язык программирования:** Python 3.10+
*   **Веб-фреймворк:** [FastAPI](https://fastapi.tiangolo.com/) — выбран за высокую производительность, автоматическую генерацию OpenAPI документации (Swagger) и поддержку асинхронности.
*   **Сервер:** [Uvicorn](https://www.uvicorn.org/) — ASGI-сервер для запуска FastAPI приложения.
*   **База данных:** SQLite (для разработки), с возможностью легкой миграции на PostgreSQL.
*   **ORM:** [SQLAlchemy](https://www.sqlalchemy.org/) — для надежной работы с реляционной базой данных и абстракции SQL-запросов.
*   **Безопасность и Аутентификация:** `PyJWT` для генерации JSON Web Tokens, `passlib` с алгоритмом `bcrypt` для безопасного хеширования паролей.

### Frontend (Клиентская часть)
*   **Технологии:** HTML5, CSS3, Vanilla JavaScript.
*   **Архитектура:** Single Page Application (SPA) логика, реализованная без тяжелых фреймворков для обеспечения максимальной скорости загрузки. Обмен данными с сервером происходит через REST API.

## Предметная область и Модель данных

### Выделение входных и выходных данных системы
*   **Входные данные:** Данные регистрации пользователей (ФИО, Email, пароль), параметры фильтрации поиска туров (страна, даты, количество ночей, звездность отеля, тип питания), запросы на бронирование.
*   **Выходные данные:** Сгенерированные JWT-токены, списки доступных туров и недвижимости (JSON), актуальные статусы заявок в личном кабинете клиента, статистика и список пользователей для панели администратора.

### Основные сущности (Таблицы БД)
1.  **Пользователи (Users):** Хранит учетные данные клиентов и менеджеров. Роль (`role`) определяет уровень доступа к системе.
2.  **Туры (Tours):** Каталог путевок. Включает поля: название, страна, курорт, название отеля, звездность, тип питания, цена, даты заезда и выезда, количество мест.
3.  **Недвижимость (Properties):** Каталог объектов для самостоятельной аренды (виллы, апартаменты). Цена рассчитывается динамически за ночь.
4.  **Заявки (Orders):** Связующее звено между пользователем и туром/объектом. Содержит статус обработки (`pending`, `confirmed` и т.д.) и зафиксированную на момент покупки цену.

## История версий (Changelog)

### Версия 6: Grayscale Academy & Level.Travel (Alternative Branch)
*   **Новый визуальный стиль:** Полный отказ от ярких тонов Vaporwave. Внедрен строгий, премиальный минимализм в градациях серого (черные фоны, тонкие белые рамки, монохром).
*   **Level.Travel Layout:** Структура переработана для максимального акцента на поиске и выдаче результатов.
*   **Анимации:** Добавлены плавные `fade-in` и `slide-up` анимации при загрузке страниц и фильтрации для улучшения пользовательского опыта.

### Версии 4 & 5: Агрегатор туров (Full-width Design)
*   **Полноэкранный макет:** Произведен отказ от оконного (Aero) макета в пользу современного полноэкранного дизайна.
*   **Виджет поиска:** Внедрен сложный интерфейс расширенного поиска по направлениям, датам, количеству туристов и ночей.
*   **Динамические фильтры:** Добавлен боковой сайдбар для фильтрации предложений по звездности и типу питания.
*   **Генерация данных:** Обновлен модуль `seed.py`, который теперь процедурно генерирует более 100 реалистичных туров и 30 объектов недвижимости с подгрузкой реальных HD-фотографий (через Unsplash API).

### Версия 3: Аренда недвижимости и Ночной режим
*   **Модуль недвижимости:** В базу данных и интерфейс добавлена сущность `Property` для аренды апартаментов и вилл.
*   **Темная тема:** Реализован полноценный ночной режим (Dark Mode) в эстетике Cyberpunk с сохранением выбора пользователя в `localStorage`.

### Версия 2: Редизайн (Aero Glass & Vaporwave)
*   **Пользовательский интерфейс:** Полная переработка визуального стиля. Внедрены эффекты полупрозрачного размытого стекла (backdrop-filter) в стилистике Frutiger Aero / Windows Vista.
*   **Рефакторинг:** Жесткое разделение Frontend-кода на изолированные файлы (HTML, CSS, JS).

### Версия 1: Базовый функционал (MVP)
*   **Архитектура:** Инициализация проекта, настройка связки FastAPI + SQLAlchemy.
*   **Безопасность:** Реализация системы регистрации и авторизации по JWT-токенам.
*   **Каталог и Заявки:** Настройка базового CRUD для туров и логики создания заказов с фиксацией цен.

## Руководство по запуску

1.  Клонируйте репозиторий и перейдите в папку проекта.
2.  Создайте виртуальное окружение:
    `python -m venv venv`
3.  Активируйте виртуальное окружение:
    *   Windows: `venv\Scripts\activate`
    *   Linux/Mac: `source venv/bin/activate`
4.  Установите необходимые зависимости:
    `pip install -r requirements.txt`
5.  Инициализируйте базу данных и наполните её тестовыми данными (выполнять обязательно при первом запуске):
    `python seed.py`
6.  Запустите сервер разработки Uvicorn:
    `uvicorn backend.main:app --reload`
7.  Откройте в браузере клиентскую часть по адресу: `http://127.0.0.1:8000/`
