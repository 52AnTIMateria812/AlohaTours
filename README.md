# NovaTours (бывш. AlohaTours) - Система работы турагентства

## 🚀 Версия 4 & 5: Агрегатор в стиле AnexTour (Full-width Design)

Проект полностью трансформирован из простой доски объявлений в мощный агрегатор туров с полноэкранным современным дизайном, сохранившим уникальную эстетику **Cyberpunk & Vaporwave**.

### Что нового (Чейнджлог Версий 4-5)
1. **Полноэкранный макет (Full-width)**
   - Отказ от ограниченного "Aero-окна". Шапка закреплена сверху, добавлен огромный Hero-баннер.
   - Карточки туров переведены в строгий горизонтальный формат (картинка слева, описание по центру, цена справа) для максимального удобства.
2. **Расширенный поиск туров**
   - Добавлен сложный виджет поиска по направлениям, датам, количеству ночей и туристов.
   - Боковая панель (Сайдбар) с динамическими фильтрами по звездностям отеля и типам питания (AI, BB, HB и т.д.).
3. **Расширенная База Данных (Масштабный Seeding)**
   - Модель данных `Tour` значительно расширена (`origin_city`, `resort`, `hotel_name`, `hotel_stars`, `board_type`, `nights`).
   - Скрипт `seed.py` теперь процедурно генерирует **100+ реалистичных пакетных туров** и **30+ объектов недвижимости** с настоящими HD-фотографиями.

## 💾 Версия 1: MVP (Минимально жизнеспособный продукт)

AlohaTours — это веб-система для управления туристическим агентством с ролевой моделью (клиенты и менеджеры).

### Технологический стек
- **Backend:** Python 3.10+, FastAPI, Uvicorn, SQLAlchemy, SQLite
- **Frontend:** Vanilla JavaScript, HTML5, CSS3
- **Безопасность:** JWT, Passlib (Bcrypt)

## Запуск
1. Создать виртуальное окружение: `python -m venv venv`
2. Активировать: `venv\Scripts\activate` (Windows)
3. Установить зависимости: `pip install -r requirements.txt`
4. Заполнить базу данных: `python seed.py`
5. Запустить бэкенд: `uvicorn backend.main:app --reload`
6. Открыть `http://127.0.0.1:8000/` в браузере.
