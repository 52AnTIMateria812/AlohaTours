# AlohaTours - Система работы турагентства (Версия 1 - MVP)

## Что это такое?
AlohaTours — это веб-система для управления туристическим агентством. Проект разделен на логические блоки и поддерживает ролевую модель: клиенты могут самостоятельно выбирать туры и оформлять заявки, а менеджеры — управлять каталогом и статусами бронирований. 

## Как это работает?
В текущей (первой) версии реализован минимально жизнеспособный продукт (MVP):
1. **Клиентская часть:** Пользователи заходят на веб-витрину (SPA на чистом HTML/JS), видят список доступных туров, могут зарегистрироваться и войти в систему (авторизация по JWT токену).
2. **Бронирование:** Авторизованные клиенты могут в один клик забронировать тур. Цена фиксируется в момент заказа.
3. **Серверная часть:** FastAPI обрабатывает REST API запросы, взаимодействует с базой данных (SQLite для MVP, структура готова под PostgreSQL) через ORM SQLAlchemy, проводит валидацию данных через Pydantic.

## Технологический стек
- **Backend:** Python 3.10+, FastAPI, Uvicorn
- **База Данных:** SQLite (локально) / PostgreSQL (продакшн), SQLAlchemy (ORM)
- **Frontend:** Vanilla JavaScript, HTML5, CSS3
- **Безопасность:** JWT (JSON Web Tokens), Passlib (Bcrypt)

## Среда разработки
- Локальное окружение (Virtualenv)
- Тестирование API: Swagger UI (встроен в FastAPI по пути `/docs`)

## Предметная область и Визуальное моделирование

### Выделение сущностей и ассоциаций
В системе выделено три базовые сущности (модели данных):

1. **User (Пользователь)**
   - Роли: `client` или `manager`.
   - Содержит персональные данные и хеш пароля.
2. **Tour (Тур)**
   - Представляет турпродукт (название, страна, даты, цена, вместимость).
3. **Order (Заявка)**
   - Связующее звено между `User` и `Tour` (многие-ко-многим с дополнительными атрибутами).
   - Содержит статус обработки и зафиксированную цену.

**Определение ассоциаций (Связи):**
- **User — Order (1:N):** Один пользователь может оформить множество заявок. Каждая заявка принадлежит ровно одному пользователю.
- **Tour — Order (1:N):** На один тур может быть оформлено множество заявок (разными пользователями). Каждая заявка привязана к одному туру.

### Выделение входных и выходных данных системы
- **Входные данные:**
  - Данные регистрации (Email, ФИО, Пароль).
  - Учетные данные для входа (Email, Пароль) -> на выходе `access_token`.
  - Данные создания тура (Название, Страна, Цена, Даты, Описание) — *только для менеджеров*.
  - Данные бронирования (ID тура) -> `user_id` берется из токена автоматически.
- **Выходные данные:**
  - Список туров (JSON массив).
  - Статусы бронирования (успешно, ошибка, нет мест).
  - Карточка пользователя/тура.

## Сложные участки кода и источники

В процессе разработки системы авторизации применялись открытые библиотеки и стандартные паттерны для FastAPI:

1. **JWT-Авторизация (OAuth2 с хешированием паролей)**
   - Реализована безопасная передача паролей и генерация токенов. Мы не храним пароли в открытом виде, используется алгоритм `bcrypt`.
   - *Источник:* Официальная документация FastAPI [Security - First Steps](https://fastapi.tiangolo.com/tutorial/security/first-steps/) и [OAuth2 with Password (and hashing)](https://fastapi.tiangolo.com/tutorial/security/oauth2-jwt/).
   - *Библиотеки:* `python-jose` для работы с JWT, `passlib` для хеширования.

2. **Внедрение зависимостей (Dependency Injection) для сессий БД**
   - Используется `Depends(get_db)` для автоматического открытия и закрытия сессий базы данных для каждого запроса.
   - *Источник:* [SQL (Relational) Databases](https://fastapi.tiangolo.com/tutorial/sql-databases/).

## Как запустить проект локально?

1. Склонируйте репозиторий.
2. Создайте виртуальное окружение: `python -m venv venv`
3. Активируйте его: `venv\Scripts\activate` (Windows) или `source venv/bin/activate` (Linux/Mac)
4. Установите зависимости: `pip install fastapi uvicorn sqlalchemy passlib[bcrypt] python-jose python-multipart pydantic-settings`
5. Запусите сервер: `uvicorn backend.main:app --reload`
6. Откройте браузер по адресу: `http://127.0.0.1:8000/` (Клиентская часть)
7. Документация API: `http://127.0.0.1:8000/docs`
