# NovaTours (Grayscale Edition) 🖤

**NovaTours** (ранее AlohaTours) — это полнофункциональный агрегатор туров и недвижимости с профессиональным бэкендом на FastAPI и строгим минималистичным фронтендом в стиле **Level.Travel** и **Grayscale Academy**.

Проект прошел путь от простого API до полноценной платформы с продвинутым поиском, JWT-аутентификацией, ролевой моделью и **умной корзиной покупок**.

## 🎯 Ключевые возможности (v6 Features)

1. **Строгий Grayscale Дизайн (Dark Mode Only)**
   - Отказ от ярких "неоновых" цветов и Aero Glass в пользу строгих, контрастных интерфейсов (черный, серый, белый).
   - Единая, монолитная панель поиска на главном экране (Hero Section).
   - Плавные `fade-in` и `slide-up` анимации для всех интерактивных элементов.
   - Минималистичная типографика на базе Google Fonts (Inter).

2. **Умное бронирование с защитой сессий**
   - Бронирование туров и аренды происходит в удобных модальных окнах с возможностью выбора дат и расчета цены на лету.
   - Система автоматически валидирует JWT-токен и отправляет запросы на бэкенд, обрабатывая нехватку мест или просроченные сессии (ошибка 401 прозрачно перехватывается с предложением перелогиниться, не ломая интерфейс).

3. **Расширенный поиск и Фильтрация**
   - Полнотекстовый поиск по странам, курортам и названиям.
   - Фильтрация по звездности (3*, 4*, 5*), типам питания (AI, BB, HB, RO), датам и количеству гостей.

4. **Защищенный Бэкенд (FastAPI + SQLite)**
   - Ролевая модель: разделение на `client` и `manager`.
   - JWT-токены с автоматическим "разлогином" (`logout`) при устаревании сессии (ошибка 401).
   - Автоматический контроль остатков мест в турах (Capacity).

## 🏗 Архитектура проекта

Проект разделен на две основные части:

*   **Backend (`/backend`)**: Построен на Python 3 с использованием **FastAPI**. Отвечает за бизнес-логику, выдачу JWT-токенов, управление БД (SQLAlchemy + SQLite) и предоставление REST API.
*   **Frontend (`/frontend`)**: Чистый Vanilla JavaScript, HTML5 и CSS3. Никаких тяжеловесных фреймворков. Общается с бэкендом через Fetch API. Включает в себя систему вкладок, модальные окна, систему корзины и рендер компонентов на лету.

## 🚀 Как запустить проект локально

### 1. Подготовка и установка зависимостей
Убедитесь, что у вас установлен **Python 3.9+**.

```bash
# Клонирование репозитория (убедитесь, что находитесь в ветке v6-grayscale)
git clone https://github.com/52AnTIMateria812/AlohaTours.git
cd AlohaTours

# Создание и активация виртуального окружения
python -m venv venv
# Для Windows:
venv\Scripts\activate
# Для Mac/Linux:
source venv/bin/activate

# Установка зависимостей (если у вас есть requirements.txt, иначе установите вручную)
pip install fastapi uvicorn sqlalchemy passlib[bcrypt] python-jose pydantic[email]
```

### 2. Инициализация Базы Данных
База данных `aloha.db` создается автоматически, но для того чтобы наполнить её турами (более 100 шт) и недвижимостью, выполните скрипт генерации:

```bash
python seed.py
```
> *Внимание: Этот скрипт очистит старые данные и создаст нового тестового администратора: `admin@alohatours.com` (пароль `admin`).*

### 3. Запуск сервера
```bash
uvicorn backend.main:app --reload
```
Сервер запустится по адресу: `http://127.0.0.1:8000/`. При открытии этой ссылки в браузере, FastAPI автоматически отдаст фронтенд (index.html).
